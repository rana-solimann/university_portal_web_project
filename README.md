# University Portal

A university portal front-end project designed to provide students and visitors with easy access to academic information, courses, instructors, and student services.

## Modules Overview

### Public Pages
Accessible to all visitors.

- `index.html` — landing page
- `about.html` — university overview
- `contact.html` — contact information
- `departments.html` — available departments
- `news.html` — latest announcements

### Academic Module
Academic browsing pages.

- `courses.html` — list of courses
- `course-details.html` — detailed course information
- `instructors.html` — instructors directory
- `instructor-profile.html` — individual instructor details

### Student System
Student-only pages after login.

- `login.html`
- `dashboard.html`
- `profile.html`
- `grades.html`

---

## User Flow

```text
Visitor enters → Home page
       ↓
Browse public pages
       ↓
Explore courses and instructors
       ↓
Login
       ↓
Student dashboard
       ├── View profile
       └── Check grades
```
