Web Programming

_ Information security Department

HTML/CSS JavaScript 3 hrs

📋 Course Description

This course introduces students to the fundamentals of web development. Students will learn how to build modern, responsive websites using HTML, CSS, and JavaScript. Topics include page structure, styling, interactivity, and an introduction to frontend frameworks.

📌 Topics Covered

  • 1 Introduction to HTML & Page Structure
  • 2 CSS Styling & Layouts (Flexbox & Grid)
  • 3 Responsive Web Design
  • 4 JavaScript Fundamentals
  • 5 Forms & Input Validation
  • 6 Frontend Development Tools
  • 6 PHP Fundamentals
